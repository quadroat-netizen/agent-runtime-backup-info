# Agent Runtime Backups – public information pages

This repository is intended to contain only the public app information pages.

- `index.html`: app description and link to the privacy notice.
- `privacy.html`: Google data use, encrypted backups, revocation and GitHub Pages hosting.

Publish GitHub Pages from `main` and `/(root)` with HTTPS.

Expected homepage: https://quadroat-netizen.github.io/agent-runtime-backup-info/
Expected privacy URL: https://quadroat-netizen.github.io/agent-runtime-backup-info/privacy.html
OAuth authorized domain: quadroat-netizen.github.io

These URLs become usable only after GitHub Pages deployment has succeeded.
Google OAuth tokens, client secrets, recovery keys and backup contents must never be added here.
